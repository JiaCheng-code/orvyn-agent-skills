Agent Skills（智能体技能）是教 AI 编程助手完成专业任务的可复用能力包。一个技能通常包含
`SKILL.md` 指令文件和配套的脚本、模板、参考资料。安装一次，之后在任何项目里都能让 AI
按标准流程执行。

[Agent Skills Hub](https://www.orvyn.top) 收录来自 Anthropic、OpenAI、Cloudflare、
Docker、Vercel 等官方组织与社区的技能仓库。每个技能都提供安装命令、GitHub 星标、
适用工具和 SKILL.md 预览。

## 为什么用 Agent Skills

- 一次安装，反复使用：把「怎么做」固化给 AI 助手，不用每次重复解释
- 跨工具通用：Claude Code、Cursor、Codex、Gemini CLI 支持同一套技能标准
- 开源可溯源：全部来自 GitHub 公开仓库，安装前可直接查看 SKILL.md

## 快速开始

```bash
# 安装一个技能（示例：Anthropic 官方技能库）
npx skills add https://github.com/anthropics/skills
```

安装后在 Claude Code / Cursor / Codex 里直接描述任务即可，AI 会按技能定义的流程执行。

## 配套站点：提示词库

技能解决「怎么做」，提示词解决「这次做什么」。两个站配套使用：

- **技能库**：[www.orvyn.top](https://www.orvyn.top) — 可复用的能力包，安装后 AI 按流程执行
- **提示词库**：[prompt.orvyn.top](https://prompt.orvyn.top) — 按场景分类的提示词，支持变量替换和一键复制
